# YAPZO NOIR — Signature V12

A visual redesign based directly on YAPZO Signature V11.

## Preserved
- `server.js`, `public/app.js`, `package.json` are byte-for-byte unchanged from V11.
- Existing DOM IDs, forms, dialog controls, chat events, and integration points remain intact.
- Original lavender star logo and custom dual-conversation-bubble chat icon remain.

## Changed
- Dark plum / obsidian visual system, editorial typography, refined layout and responsive styling.
- Larger low-opacity wordmark watermark, soft ambient background, premium buttons, cards, and chat surfaces.
- Updated introductory marketing copy and removed compass-style surprise icons.

## Deploy
Upload the files in this ZIP to the repository root (not into a new nested folder), keeping `public/` structure. On Render use `npm start`; Node 20+ required. Existing environment variables, database and payment integrations (if configured) are not modified.

## Important
This is a design update, not an audit of safety, privacy, moderation, database persistence, payments or translation. Some backend-dependent features require service configuration and should not be marketed as fully available until verified. Test on a staging deployment before replacing production.
